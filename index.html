Secure Topic-Constrained AI Chatbot with Layered Guardrails

QUT University Project • May 2026

A multi-turn chatbot in Python on Azure OpenAI (GPT-4.1-mini, text-embedding-ada-002) that wraps every turn in a six-layer guardrail pipeline.

  • Layered a token cap, a normalised keyword denylist, embedding similarity against 26 jailbreak archetypes, topic-anchor similarity, and an LLM-as-a-Judge on both input and output.
  • Judge verdicts deny rather than pass through: users receive a generic refusal while the triggering layer, category and similarity scores are written to a rotating JSON audit log, denying attackers the feedback needed to tune bypasses.
  • Tested against prompt-injection, persona-escape, system-prompt-extraction and obfuscation attacks with no successful bypasses across 50+ logged decisions.

Detection Engineering Homelab

Personal Project • July 2026 – Present

A detection engineering lab built from scratch on Proxmox VE. Segmented environment with a Windows Active Directory domain, Wazuh single-node SIEM, and deliberately vulnerable targets, with pfSense enforcing isolation between lab and host networks. Attack activity is emulated from a Kali VM and mapped to MITRE ATT&CK, driving custom detection rules and tuning against real telemetry. Backed by ZFS mirrored storage and UPS-managed graceful shutdown.
